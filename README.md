# Pervasive Computing – Gandalf Staff

ESP32-E project to build an interactive Gandalf staff.  

## Structure
```
📂 Root  
│── 📂 01_Code  
│       │── 📂 firmware -> PlatformIO project (ESP32 + Arduino framework)  
│                │── 📂 include -> Project headers  
│                │── 📂 platformio.ini -> Build configuration  
│                │── 📂 src -> main.cpp and implementation files  
│── 📂 02_Doc  
│       │── 📂 01_Example -> Example sketches  
│── 📜 README.md  
│── 📜 .gitignore  
```
