PLZ connect the neo16 gps module with firebeetle esp32-e by the following:
1. RX -> GPIO17 (unnnecessary)
2. TX -> GPIO16
3. VCC -> VCC
3. GND -> GND

this is for printing all the info regarding gps coordinates from the satellite.
to use this code, simply calling GPSManager on main.cpp like:
#include "GPS_Coords.h"

void setup() {
    Serial.begin(115200);
}

void loop() {
    String coords = GPS_Coords();
    Serial.println(coords);
    delay(2000);
}
